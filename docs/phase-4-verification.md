# Phase 4 — กราฟวิเคราะห์ข้อมูล

เปิดแท็บตารางและสถิติ เลือกคอลัมน์แบ่งกลุ่ม วิธีคำนวณ และคอลัมน์ตัวเลข แล้วกดสร้างกราฟ รองรับกราฟแท่งและกราฟสัดส่วน พร้อมตารางค่าจริง

ใช้ข้อมูลทั้งหมดจาก Python รวมกลุ่มค่าว่างและแสดงทุกกลุ่มภายในขอบเขต 200 กลุ่ม กราฟแท่งมีจุดอ้างอิงศูนย์และรองรับค่าติดลบ ค่าที่คำนวณไม่ได้แสดงในตารางเป็นไม่มีค่าตัวเลข กราฟสัดส่วนเปิดใช้เฉพาะ sum/count ที่ไม่มีค่าติดลบหรือ null และผลรวมมากกว่าศูนย์

คำขอกราฟตรวจเจ้าของด้วย dependency เดียวกับ API ข้อมูล และตรวจชีตที่คาดหวังเพื่อป้องกันหน้าจอเก่าหลังเปลี่ยนชีตจากอีกหน้าต่าง การตั้งค่ากราฟเก็บระหว่างเปิดหน้า ไม่บันทึกถาวรข้าม refresh การส่งออกรายงานและกราฟขั้นสูงอยู่ในงานถัดไป

ตรวจ API ใหม่ผ่าน 6 รายการ ครอบคลุมผลรวม จำนวนแถว ค่าว่าง คอลัมน์ผิด และชีตที่ถูกเปลี่ยน ทดสอบ browser จริงบนบัญชีผู้ใช้ เปิดชีต About & Questions ของไฟล์ Iris จำนวน 8 แถว แสดง 8 กลุ่ม และค่าตารางแต่ละกลุ่มเป็น 1 ตรวจสลับกราฟแท่งและกราฟสัดส่วนแล้ว

การตรวจสิทธิ์ข้ามสองบัญชียังเป็นงานค้างก่อนเปิดออนไลน์ตาม Phase 2
