# Phase 1 Core System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้เปิดเว็บในเครื่อง อัปโหลด CSV/XLSX เลือก sheet ดูตารางแบบแบ่งหน้าและสถิติที่ Python คำนวณจริงได้

## Global Constraints
- ห้ามสร้างข้อมูลตัวเลขหรือผลวิเคราะห์ปลอมเพื่อแสดงผลเสมือนจริง
- ใช้ Python ในการคำนวณและวิเคราะห์ข้อมูลจริง
- เก็บ API Keys ไว้ใน Environment Variables เท่านั้น
- รองรับ Excel (.xlsx), CSV (.csv), ภาษาไทยและ UTF-8
- มี error/loading/empty states และไม่แก้ข้อมูลต้นฉบับเงียบ ๆ
- Phase 1 local-only: bind 127.0.0.1, exact localhost origin, no auth claims
- ไม่ทำ Gemini, charts, PDF, auth หรือ production deployment ในแผนนี้

## Review Focus
1. CSV ภาษาไทย BOM, quoted multiline, malformed rows: อ่านถูกหรือคืนข้อความผิดพลาด ไม่ข้ามแถวเงียบ ๆ (Task 2)
2. XLSX zip bomb, formulas without cached values, empty sheets: จำกัดทรัพยากรและเตือน (Task 2)
3. Empty/all-null/non-finite numeric data: JSON เป็น null ไม่มี NaN/Infinity และแยก unavailable ออกจาก zero (Task 3)
4. Duplicate/blank headers and date ambiguity: รักษา mapping ชื่อเดิม ไม่เดาวันเดือนหรือแปลงข้อมูลเงียบ ๆ (Task 2)
5. Expired datasets, concurrent selection and server failures: ไม่แสดงผลเก่าทับไฟล์ใหม่และแจ้งให้อัปโหลดอีกครั้ง (Tasks 4–5)

## API contract
- POST /api/v1/datasets multipart file → 201 {id,filename,sheets:[{name}],selected_sheet:null|string,status:"needs_sheet"|"ready",expires_at,warnings:[]}. CSV auto-selects; XLSX requires explicit sheet selection.
- POST /api/v1/datasets/{id}/sheet {sheet_name:string} → 200 metadata with status ready; use exact workbook sheet name.
- GET /api/v1/datasets/{id}/preview?offset=0&limit=50&search= → {columns:[{id,label,dtype}],rows:Record<string,JsonScalar>[],total_rows,filtered_rows,offset,limit}; max limit 200, search ≤200 chars, literal case-insensitive substring across displayed cells.
- GET /api/v1/datasets/{id}/statistics → {row_count,column_count,missing_cells,rows_with_missing,duplicate_rows,numeric:[{column_id,count,missing,sum,mean,median,min,max}],warnings:[]}
- DELETE /api/v1/datasets/{id} → 204, removes temp data; GET /health → {status:"ok"}
- JSON error envelope {error:{code,message,details?}}; 413 size, 415 format, 422 parse/validation, 404 missing/expired, 409 sheet not selected, 500 sanitized unexpected error.
- JsonScalar = string | number | boolean | null. Column ids c0,c1… separate from original labels. Duplicate count uses duplicated(keep="first"). Missing counts include null/empty parsed cells, not literal text "NA".
