# Phase 3 — Gemini chat implementation

Goal: natural-language questions over an owned dataset, validated computation tools, clarification and evidence.

Use Gemini only to produce a validated JSON analysis plan from column names/types and recent conversation. Execute overview, numeric summary and grouped aggregates using Python. Render answers from computed evidence to keep numeric claims traceable. Clarify unsupported or ambiguous requests. Do not send original files or row values to Google. A user-facing notice explains that questions and column labels are sent to Gemini.

Store the bounded conversation in dataset metadata using the repository's existing ownership and optimistic version checks. No additional database migration is needed. Preserve sheet and parsed-object identity per turn. A sheet change resets visible conversation by sheet/version key. Missing API key returns an explicit configuration error.
